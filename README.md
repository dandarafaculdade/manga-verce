# MangaVerse

O MangaVerse é um projeto de site de recomendações de mangás japoneses, desenvolvido para a disciplina de Desenvolvimento de Aplicações Web.

## Objetivo

Apresentar recomendações de mangás e destacar personagens de diferentes obras, em uma interface responsiva inspirada na estética dos mangás japoneses.

## Estrutura da página

- Cabeçalho com identificação do projeto e navegação.
- Área principal de destaque.
- Biblioteca com pelo menos 10 recomendações de mangás.
- Seção com pelo menos 3 personagens em destaque.
- Rodapé.

## Responsividade

O projeto será desenvolvido seguindo a abordagem mobile first, com layouts adaptados para dispositivos móveis, tablets e desktops.
